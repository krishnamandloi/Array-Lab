About ArrayLab

ArrayLab is a web-based educational simulation created to demonstrate fundamental array operations in an interactive and visual way. The project does not simply show the final answer. It demonstrates the internal steps performed by algorithms so that students can understand the underlying logic.

  • Array address calculation
  • Insertion with shifting visualization
  • Deletion with shifting visualization
  • Step-by-step linear search
  • Step-by-step binary search
  • Interactive practice quiz
  • Operation history
  • Responsive web interface

Complexity

  • Address O(1)
  • Insertion O(n)
  • Deletion O(n)
  • Linear Search O(n)
  • Binary Search O(log n)
